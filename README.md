# Global Languages

Página institucional de una escuela de idiomas, realizada en Angular con la estructura HTML5 `header`, `main`, `aside` y `footer`. Su diseño prioriza una presentación clara, una portada con fotografía, información concreta de los cursos y una paleta de colores discreta. Bootstrap 5.3.8 se carga mediante CDN desde `src/index.html`.

## Iniciar el proyecto

```bash
npm install
npm start
```

Abre `http://localhost:4200/` en el navegador.

## Componentes existentes

- `PrimerComponente`: encabezado y navegación responsive.
- `SegundoComponente`: presentación, idiomas, programas, testimonio e historia.
- `TercerComponente`: horarios, promoción, docentes y contacto.
- `CuartoComponente`: pie de página.

Los nombres de docentes, horarios, testimonio y promoción son de demostración; reemplázalos por la información real de la institución.
